# RNAseq Equipo 4 — Análisis de expresión diferencial en Down syndrome

## Integrantes

- Rubií Martínez Chavarría (rmartinez)

## Fecha
Mayo 2026 — Bioinformática y Estadística II

## Resumen
Análisis de RNA-seq de hígado de ratón comparando wild-type (WT) vs Dp16 (modelo de Down syndrome). Datos del bioproyecto PRJNA1259260.

## Pipeline
1. Control de calidad (FastQC/MultiQC)
2. Trimming de adaptadores (Trimmomatic)
3. Pseudoalineamiento (Kallisto)
4. Alineamiento (STAR)
5. Expresión diferencial (DESeq2)
